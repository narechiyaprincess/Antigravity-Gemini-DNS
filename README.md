# Antigravity-Gemini DNS

DNS/DoH-мост для **Antigravity, Gemini и выбранных сервисов Google в Windows**. Проверяет провайдеров и создаёт правила разрешения имён только для выбранных сервисов. Portable EXE, интерфейс RU/EN.

**[Скачать последний выпуск](https://github.com/narechiyaprincess/Antigravity-DNS/releases/latest)** · [English](docs/EN/README.md) · [Изменения](CHANGELOG.md) · [Помощь](docs/TROUBLESHOOTING.md)

Исходники подготовлены к **v1.1.0**. До её публикации ссылка загрузки ведёт на предыдущий выпуск; сверяйте версию на странице релиза. Условия v1.1.0: Windows 11 x64, Windows PowerShell 5.1 и работающий CIM/WMI. Runtime включён в EXE; устанавливать .NET для запуска не требуется. EXE не подписан.

## Быстрый старт

1. Скачайте EXE из Releases, сверьте SHA-256 с `SHA256SUMS.txt` и поместите его в постоянную папку.
2. **При обновлении с 1.0.0 сначала отключите мост старой версией, убедитесь в восстановлении и закройте её.** Только затем запускайте 1.1.0. Не запускайте две версии одновременно.
3. Выберите нужные сервисы и профиль на вкладке «Мост». При желании выполните «Замер» и выберите работающий профиль.
4. Нажмите «Подключить мост», подтвердите доверие провайдерам и запрос Windows (UAC). Если прямой доступ уже работает, программа может обойтись без создания моста.
5. Проверьте нужный сервис. Для отмены изменений используйте «Отключить мост» / «Восстановить» и подтвердите UAC. Закрытие окна или выход из трея сами по себе DNS не восстанавливают.

## Возможности

- Независимый выбор Antigravity, Gemini и Google/browser-сервисов; встроенные профили и пользовательский DoH.
- Замер доступности и задержек, выбор лучшего из свежих результатов, история замеров.
- Подключение с проверкой состояния и восстановлением собственных правил; сохранение чужих или изменённых записей.
- Doctor: диагностика сети, DNS-политики, провайдера и возможных конфликтов с VPN или Secure DNS браузера.
- Перенос предпочтений через файл; локальный отчёт для поддержки с предпросмотром; RU/EN, трей, уведомления и автозапуск.

В **1.1.0** переработаны подключение и выбор сервисов, добавлены direct-first и Doctor, усилены проверки актуальности результатов и владения системными настройками, обновлён каталог и доработан интерфейс. RU/EN, трей, обычный автозапуск, custom DoH, benchmark и базовое восстановление уже были в 1.0.0. Подробности — в [заметках 1.1.0](docs/RELEASE-NOTES-1.1.0.md).

## Как работает и кому вы доверяете

Программа использует Windows NRPT и DoH для доменов из встроенного каталога. SmartDNS-провайдер может возвращать адреса своего SNI-прокси. Это требует доверия к стороннему DNS/SNI-провайдеру: он получает DNS-запросы выбранных сервисов и может участвовать в передаче их трафика. DoH шифрует DNS-запросы к провайдеру; весь трафик компьютера не туннелируется.

Одно согласие распространяется на встроенный каталог провайдеров; пользовательский DoH подтверждается отдельно для его адреса и выбранных сервисов. Доверие можно отозвать в настройках. TLS-сертификаты продолжают проверяться. Подключение/восстановление требует прав администратора; обычный процесс не вызывает фоновый UAC для автоматической починки.

## Ограничения и обновление

- Это не VPN. Успешные DNS/TLS-проверки не гарантируют вход в аккаунт, доступ к модели или работу сервиса в вашей сети.
- VPN/TUN, корпоративные правила и Secure DNS браузера могут обходить системный DNS. Приложение не перенастраивает их автоматически.
- Windows 10, ARM64 и чистая Windows без среды разработчика не подтверждены. Неподписанный EXE может вызвать предупреждение Windows.
- Открыты два P2: изменение второстепенного сетевого адаптера иногда консервативно отменяет операцию; ускоренный путь подтверждения результата не используется обычным координатором. Обещания ускорить подключение на 6–8 секунд нет.
- До обновления или отката отключайте мост той версией, которая его создала. Не удаляйте журнал `state.json` и не очищайте NRPT вручную. [Совместимость и переход](docs/COMPATIBILITY-IDENTIFIERS.md).
