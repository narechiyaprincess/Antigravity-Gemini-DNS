# Antigravity-Gemini DNS

**Русский** · [English](docs/EN/README.md)

Antigravity-Gemini DNS — программа для Windows, которая подбирает рабочий DNS/DoH-профиль и включает его только для выбранных сервисов: Antigravity, Gemini и связанных сервисов Google в браузере. Остальная сеть компьютера продолжает работать как раньше.

**[Скачать последний выпуск](https://github.com/narechiyaprincess/Antigravity-DNS/releases/latest)** · Windows 11 x64 · portable EXE, установка .NET не нужна · [что нового](CHANGELOG.md)

> Исходники в `main` соответствуют версии 1.1.0. Пока её релиз не опубликован, по ссылке загружается 1.0.0. Перед обновлением с 1.0.0 прочитайте [порядок перехода](docs/RELEASE-NOTES-1.1.0.md#обновление-с-100-и-откат).

## Что умеет

- **Выбор сервисов.** Antigravity, Gemini и браузерные сервисы Google включаются независимо: мост затрагивает только отмеченные.
- **Замер профилей.** Проверка доступности, задержки и TLS у встроенных DNS/DoH-профилей, подсказка лучшего по свежим результатам и история замеров. Можно добавить свой DoH-провайдер.
- **Сначала напрямую.** Если прямой доступ к сервису подтверждён, мост не создаётся и системные настройки не меняются.
- **Аккуратное подключение и отключение.** Программа меняет только свои правила разрешения имён и умеет их убрать. Чужие или изменённые записи не трогает.
- **Диагностика.** Проверяет сеть, правила DNS, провайдера, конфликты с VPN и Secure DNS браузера и показывает результат каждой проверки отдельно.
- **Повседневное.** Русский и английский интерфейс, значок в трее, уведомления о сбоях, автозапуск, перенос настроек файлом и отчёт для поддержки с предпросмотром.

## Быстрый старт

1. Скачайте EXE со страницы релиза, сверьте SHA-256 с файлом `SHA256SUMS.txt` и положите программу в постоянную папку.
2. На вкладке «Мост» выберите сервисы и DNS-профиль. Чтобы выбрать профиль по факту, откройте «Замер» и нажмите «Измерить».
3. Нажмите «Подключить мост», подтвердите доверие провайдеру и запрос Windows (UAC), если он появится.
4. Проверьте сам сервис: подключённый мост ещё не означает, что вход в аккаунт или доступ к модели заработают.
5. Чтобы вернуть всё как было, нажмите «Отключить мост» или «Восстановить». Закрытие окна или выход из трея DNS не восстанавливают.

## Как это работает и кому вы доверяете

Для доменов выбранных сервисов программа создаёт правила Windows NRPT и направляет их DNS-запросы к выбранному DoH-провайдеру. Такой провайдер может вернуть адреса своего прокси, и тогда часть трафика этих сервисов проходит через него. Поэтому провайдер — сторона, которой вы доверяете: он видит DNS-запросы выбранных сервисов и может участвовать в передаче их трафика. DoH шифрует сами DNS-запросы, но не весь трафик компьютера. Проверка TLS-сертификатов при этом остаётся включённой.

- Это не VPN и не гарантия доступа: успешная проверка DNS и TLS не обещает, что аккаунт, модель или сервис заработают в вашей сети.
- VPN/TUN, корпоративные политики и Secure DNS браузера могут обходить системный DNS; программа их не перенастраивает, но диагностика подскажет конфликт.
- Подключение и восстановление требуют прав администратора. Фоновая автоматическая починка UAC не вызывает; если включить «Запуск от администратора», после первого подтверждения операции выполняются без новых запросов. EXE не подписан, поэтому Windows может показать предупреждение.
- Проверенная платформа — Windows 11 x64 с PowerShell 5.1 и работающим CIM/WMI. Windows 10, ARM64 и чистая установка Windows не проверялись.
- Встроенным провайдерам доверие даётся один раз для каталога, своему DoH-провайдеру — отдельно. Отозвать доверие можно в настройках.

Известные ограничения текущей версии перечислены в [заметках к выпуску](docs/RELEASE-NOTES-1.1.0.md#ограничения-и-границы-проверки).

## Antigravity из России

Мост открывает дорогу к серверам, но у Antigravity есть второй замок — проверка региона. Из России он обычно упирается в неё даже при рабочем DNS. Этот замок снимает [Open Antigravity Patcher](https://sourceforge.net/projects/open-antigravity-patcher/) от avencores: патч для Antigravity 2.0, IDE и CLI без VPN и без смены региона Google-аккаунта. Связка простая: патчер — для самого Antigravity, этот мост — для сети.

Патчер — отдельный сторонний проект: мы его не разрабатываем и не проверяем. Прочитайте его страницу, прежде чем запускать.

## Для разработчиков

Сборка из корня репозитория с SDK из `global.json`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\app\Build.ps1
```

Результат — `src\.work\build\AntigravityGeminiDns.exe`. Рецепт сохраняет полный WinForms runtime (`PublishTrimmed=false`).
