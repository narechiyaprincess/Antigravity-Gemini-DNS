## Что умеет

- <img src="assets/icons/globe.svg" width="16" height="16" alt=""> **Выбор сервисов.** Antigravity, Gemini и браузерные сервисы Google включаются независимо: мост затрагивает только отмеченные.
- <img src="assets/icons/gauge.svg" width="16" height="16" alt=""> **Замер профилей.** Доступность, задержка и TLS у встроенных DNS/DoH-профилей, выбор лучшего по свежим результатам и история замеров. Можно добавить свой DoH-провайдер.
- <img src="assets/icons/check.svg" width="16" height="16" alt=""> **Сначала напрямую.** Если прямой доступ к сервису подтверждён, мост не создаётся и системные настройки не меняются.
- <img src="assets/icons/power.svg" width="16" height="16" alt=""> **Аккуратное подключение и отключение.** Программа меняет только свои правила разрешения имён и умеет их убрать. Чужие или изменённые записи не трогает.
- <img src="assets/icons/info.svg" width="16" height="16" alt=""> **Диагностика.** Проверяет сеть, правила DNS, провайдера, конфликты с VPN и Secure DNS браузера и показывает результат каждой проверки отдельно.
- <img src="assets/icons/gear.svg" width="16" height="16" alt=""> **Повседневное.** Русский и английский интерфейс, значок в трее, уведомления о сбоях, автозапуск, перенос настроек файлом и отчёт для поддержки с предпросмотром.

## Быстрый старт

1. Скачайте EXE и положите его в постоянную папку, которую не будете переносить или удалять.
2. На вкладке «Мост» выберите сервисы и DNS-профиль. Чтобы взять лучший профиль по свежим данным, откройте «Замер», нажмите «Измерить», а затем «Выбрать лучший».
3. Нажмите «Подключить мост», подтвердите доверие провайдеру и запрос Windows (UAC), если он появится.
4. Проверьте сам сервис: подключённый мост ещё не означает, что вход в аккаунт или доступ к модели заработают.
5. Чтобы вернуть всё как было, нажмите «Отключить мост» или «Восстановить». Закрытие окна или выход из трея DNS не восстанавливают.

## Как это работает и кому вы доверяете

Для доменов выбранных сервисов программа создаёт правила Windows NRPT и отправляет их DNS-запросы выбранному DoH-провайдеру. Провайдер может вернуть адреса своего прокси, и тогда часть трафика этих сервисов пойдёт через него.

Поэтому провайдер — сторона, которой вы доверяете: он видит DNS-запросы выбранных сервисов и может участвовать в передаче их трафика. DoH шифрует сами DNS-запросы, но не весь трафик компьютера. Проверка TLS-сертификатов остаётся включённой.

- Это не VPN и не гарантия доступа: успешная проверка DNS и TLS не обещает, что аккаунт, модель или сервис заработают в вашей сети.
- VPN/TUN, корпоративные политики и Secure DNS браузера могут обходить системный DNS. Программа их не перенастраивает, но диагностика покажет конфликт.
- Подключение и восстановление требуют прав администратора. Фоновая починка UAC не вызывает; если включить «Запуск от администратора», после первого подтверждения операции идут без новых запросов.
- EXE не подписан, поэтому Windows может показать предупреждение.
- Проверенная платформа — Windows 11 x64 с PowerShell 5.1 и работающим CIM/WMI. Windows 10, ARM64 и чистая установка Windows не проверялись.
- Встроенным провайдерам доверие даётся один раз для всего каталога, своему DoH-провайдеру — отдельно. Отозвать доверие можно в настройках.

Известные ограничения текущей версии — в [заметках к выпуску](docs/RELEASE-NOTES-1.1.0.md#ограничения-и-границы-проверки).

## Antigravity из России

Мост открывает дорогу к серверам, но у Antigravity есть второй замок — проверка региона. Из России он обычно упирается в неё даже при рабочем DNS.

Этот замок снимает [Open Antigravity Patcher](https://sourceforge.net/projects/open-antigravity-patcher/) от avencores: патч для Antigravity 2.0, IDE и CLI без VPN и без смены региона Google-аккаунта. Связка простая: патчер — для самого Antigravity, этот мост — для сети.

Патчер — отдельный сторонний проект: мы его не разрабатываем и не проверяем. Прочитайте его страницу, прежде чем запускать.

## Для разработчиков

Сборка из корня репозитория с SDK из `global.json`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\src\app\Build.ps1
```

Результат — `src\.work\build\AntigravityGeminiDns.exe`. Рецепт сохраняет полный WinForms runtime (`PublishTrimmed=false`).
