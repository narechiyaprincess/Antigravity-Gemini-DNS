# Безопасность

Приложение меняет domain-scoped NRPT и регистрирует DoH только после явного
подключения с UAC. Выход из окна не заменяет отключение/восстановление.
DNS-провайдер получает имена выбранных сервисов и участвует в маршрутизации;
это требует доверия и не даёт гарантии анонимности или доступа к аккаунту.

При ошибке восстановления сохранить журнал и сообщение, не удалять вручную
весь NRPT/DoH или чужие правила. Пользоваться инструкциями по точному owner и
fingerprint из журнала. Не передавать непроверенные scripts elevated.

Сообщать об уязвимости владельцу через контакт, указанный в публичном профиле
[репозитория](https://github.com/narechiyaprincess/Antigravity-DNS). Не размещать
в публичном issue токены, полный журнал, SSID, личные пути или неретушированные
support reports. Private reporting availability не заявляется без проверки.

Публичный self-contained EXE может быть неподписанным. SHA-256 позволяет сверить
полученный файл с опубликованной контрольной суммой, но не заменяет доверие
к источнику самой суммы.
