# Antigravity-Gemini DNS 1.1.0

Подготовлено 26.10.2026. Дата публикации не назначена; GitHub Release создаётся отдельно после проверки репозитория. [English](RELEASE-NOTES-1.1.0-EN.md).

## Изменения относительно 1.0.0

- Независимый выбор Antigravity, Gemini и Google/browser-сервисов; минимум одна группа.
- Direct-first: при подтверждённом прямом доступе мост не создаётся. Обычный GUI использует координатор подготовки, применения, проверки и восстановления, с отменой и защитой от устаревших результатов.
- Doctor и более точные статусы: DNS-политика, доступность провайдера и готовность приложения показываются раздельно.
- Усилены владение NRPT/DoH, журналирование, восстановление и обработка неопределённых операций. При неоднозначном владении программа сохраняет записи и сообщает об отказе.
- Перенос предпочтений через файл без machine journal; более устойчивое сохранение и миграция настроек. Отдельный opt-in повышенный автозапуск использует защищённую копию и проверку владения задачей.
- Сетевой бюджет замера — 10 секунд вместо 30; завершение отмены и отображение могут добавить время. Это не обещание длительности подключения.
- Обновлены профили, интерфейс, DPI, история и сообщения. Полный WinForms runtime включён без trimming; single-file compression включено, ReadyToRun выключено.

RU/EN, tray, обычный автозапуск, custom DoH, benchmark и базовое восстановление существовали в 1.0.0.

Доступны `dns.malw.link` (default), `dns.comss.one`, `dns.bezmezhau.com`; experimental — `geohide.ru`, `dns.zapret.moe`, `eu.geohide.ru`. Адреса COMSS/Bezmezhau обновлены. `xbox-dns.ru` и `dns.dns-ai.ru` выведены; их ID не переиспользуются. Сохранённый retired-выбор переходит на default с сообщением в логах; уже подключённый retired-мост остаётся видимым и отключаемым. Работавший подтверждённый профиль предпочитается экспериментальному. Каталог не гарантирует доступность в вашей сети.

## Обновление с 1.0.0 и откат

1. Отключите мост той старой версией, которая его создала.
2. Убедитесь, что восстановление завершено; закройте старую версию.
3. Затем запускайте 1.1.0. Не запускайте две версии одновременно.

Папки настроек и журнала сохранены. Это не разрешение переносить активный мост между версиями. После записи журнала Schema 2 старый движок Schema 1 не сможет его прочитать. Перед откатом отключите мост версией 1.1.0. Не удаляйте `state.json`, не очищайте NRPT/DoH вручную. [Совместимость](COMPATIBILITY-IDENTIFIERS.md) · [Восстановление](TROUBLESHOOTING.md).

## Ограничения и границы проверки

Windows 11 x64, PowerShell 5.1, работающий CIM/WMI; EXE unsigned и self-contained. Windows 10, ARM64 и отдельная clean-Windows acceptance не подтверждены. Программа не VPN и не гарантирует доступ аккаунта или модели. DoH защищает DNS-запросы к провайдеру; DNS/SNI-провайдер остаётся стороной доверия. VPN/TUN и браузерный Secure DNS могут обходить системные правила.

Два P2 остаются открытыми:

- Изменение второстепенного сетевого адаптера может консервативно отменить подготовку/подключение/отключение до изменения политики. Native-контекст ещё учитывает все NIC.
- Ускоренное подтверждение по результату движка не используется обычным координатором; выполняется полная диагностика. Ускорение подключения на 6–8 секунд не заявляется.

Сохранённый аудит эталонного комплекта сообщает 2075 self-tests, 451/451 offline E2E и synthetic UI/DPI/standalone PASS. Это результаты предыдущего локального прохода, а не статус GitHub Actions. Свежие результаты интеграции фиксируются отдельно. Live DNS apply/restore, UAC, reboot/logon и работа аккаунтов в данном проходе не проверяются.

Обычный coordinator входит в GUI. Прямые `--enable`/`--restore` вызывают engine отдельно. Broker-служба и локальный подписанный каталог остаются экспериментальными; ошибка остановки broker 1061 не перевалидирована. [Архитектура](TECHNICAL.md) · [Assisted contract](../src/ASSISTED.md).
